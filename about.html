About this project

This site is part of a three-part web development project for IT 3203. Its topic is progressive web apps. The goal is to build a plain, readable information site with no templates or frameworks.

  1. Milestone 1. Six pages of content written in HTML and styled with one CSS file.
  2. Milestone 2 (this version). A ten-question quiz page built with JavaScript and an HTML form, plus more key concepts and references.
  3. Milestone 3. A responsive layout for phones and tablets, plus finished research.

The content will grow as the research continues. The class website is at ksuweb.github.io/IT3203.
