Progressive web apps: websites that behave like apps

A progressive web app (PWA) is a website built with standard web technologies that can be installed on a device, load without a network connection, and send notifications. This site explains how PWAs work, how developers build them, and which ideas a beginner should learn first. The topic goes beyond basic HTML and CSS and connects to JavaScript, browser storage, and web security.

Key terms

Progressive web app (PWA)
A website that uses a manifest and a service worker so it can be installed and used offline.
Service worker
A JavaScript file that runs in the background and controls how a page gets its files.
Web app manifest
A JSON file that gives the browser the app name, icons, colors, and start page.
App shell
The minimum HTML, CSS, and JavaScript needed to show the app's basic interface.
Cache API
A browser feature for storing copies of network responses on the device.
Installability
The ability of a browser to add a site to the home screen, dock, or app list.
